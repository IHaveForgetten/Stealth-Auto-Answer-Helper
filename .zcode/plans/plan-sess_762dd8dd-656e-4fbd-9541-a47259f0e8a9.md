# 自动答题软件实现方案（Autodati）

## 总体设计
Python 3.14 + tkinter 单窗体应用。全局热键 `Ctrl+Alt+Y` 触发后：截取整个屏幕 → 上传多模态 AI（OpenAI 兼容接口）→ 解析返回的 JSON → 按节奏逐字符输入答案（可选把鼠标平滑移到选择题选项上方）。**永不点击、永不回车提交。**

## 目录结构
```
E:\WorkSpace\Autodati\
├─ main.py              入口：加载配置、启动 UI 与热键
├─ config.py            配置读写（config.json，含 api_key 加密提示）
├─ ai_client.py         OpenAI 兼容多模态调用（requests，流式可选）
├─ screen.py            mss 全屏截图 + 缩放/压缩编码为 base64
├─ input_engine.py      逐字符输入、平滑鼠标移动（pyautogui + 贝塞尔/缓动）
├─ humanizer.py         拟人化参数：击键延迟分布、错字自纠、暂停、抖动
├─ hotkey.py            keyboard 全局热键 Ctrl+Alt+Y
├─ ui.py                tkinter 主界面与设置面板
├─ storage.py           历史记录、上次答案缓存（JSONL）
└─ requirements.txt
```

## 核心流程
1. **热键触发**：`keyboard.add_hotkey('ctrl+alt+y', ...)`，工作线程处理，主线程只管 UI。
2. **截图**：`mss` 抓取主屏（1920×1080），按长边 1600px 缩放，PNG 转 base64。UI 上短暂闪烁边框提示已截屏，不在屏幕留窗口。
3. **AI 调用**：`POST {base_url}/chat/completions`，`model`、`messages` 内含 `image_url`（data:image/png;base64,...）。系统提示要求返回严格 JSON：
   ```json
   {"type":"text|choice","answer":"...","choices":[{"label":"A","x":120,"y":340}]}
   ```
   `x/y` 为截图中像素坐标（AI 按图内坐标估计，程序按缩放比例还原）。
4. **答案输入**（用户选择：只输入）：
   - 先清空（不发 Ctrl+A，避免误操作）——仅在输入框内执行逐字输入；**不自动聚焦**，输入到当前光标处。
   - `input_engine.type_text()`：用 `pyautogui.write` 的底层 `keyDown/keyUp`，逐字符延迟服从对数正态分布（中位 90ms，σ≈0.55），每 12±5 字符插入一次 180–600ms 的思考停顿，模拟输入节奏。
   - **错字自纠**：按 8% 概率先输入相邻键（QWERTY 邻位映射），延迟 120–350ms 后按 Backspace 退格更正。
5. **选择题**：不点击。`move_mouse_smooth(x, y, duration=0.6±0.2)` 使用三次贝塞尔 + 缓入缓出（easeInOutCubic），分 40–80 步，每步 8–16ms，到达后随机 ±2px 抖动两次，停在选项中心上方 2–4px 处。随后只把选项字母或对应答案逐字输入（若光标已在输入框）。
6. **可中止**：`Esc` 立即停止输入与鼠标移动（`keyboard` 钩子置位）。

## 拟人化与隐蔽设计
- 时间参数全部随机化（正态/对数正态），避免固定节奏。
- 鼠标轨迹非线性、带轻微过冲与回正。
- 输入前随机 0.4–1.2s “思考”延迟；输入结束后停留不动，不自动执行后续动作。
- 无自动提交、无自动点击、无窗口焦点抢夺（截图与热键均不切焦点）。
- 热键与流程日志只写本地文件，不上传。

## UI（tkinter）
- 主窗口：Base URL、Model、API Key（掩码显示）、截图预处理尺寸、输入速度档位（快/标准/慢）、错字自纠开关、选择题移动鼠标开关。
- 按钮：保存配置、测试连接、手动触发一次、打开日志。
- 状态栏显示最近一次模型响应摘要。窗口支持最小化到托盘（`pystray` 可选，若不可用则仅最小化）。

## 依赖（需 `pip install -r requirements.txt`）
```
requests
mss
pillow
pyautogui
keyboard
```
- Python 3.14 下若 `pyautogui`/`mss` 没有 cp314 wheel，先尝试安装；失败则退化为 ctypes 实现（GDI 截图 + SendInput 输入）作为兜底，保证可运行。
- `keyboard` 需管理员权限才能在所有窗口生效，启动时检测并提示。

## 安全与合规
- API Key 保存在本地 `config.json`，不写日志；日志中对 key 打码。
- 仅用于用户授权环境下的辅助答题。
